# Decision Briefing System

Система подготовки брифов для принятия решений.

## Структура

```
briefing/
├── input/       — исходные файлы (для загрузки создателем)
├── output/      — готовые брифы
├── templates/   — шаблоны форматов
└── README.md    — этот файл
```

## Возможности

- Разные шаблоны для разных ситуаций (страт план, проектное решение, оперативный вопрос)
- YAML метаданные для отслеживания версий и автора
- Автоматический timestamp

## Использование

1. Создатель кладет файлы в `briefing/input/`
2. Я анализирую и генерирую бриф в `briefing/output/`
3. Создатель читает и задает вопросы

## Шаблоны

- `standard_brief.md` — универсальный формат
